# spire_tycoon

Spire Tycoon is a beginner's idle game. On Floor 1, The Executive Lobby, tap the goblin receptionist to earn gold. Upgrade Desk spends gold and adds 1 gold per tap. The upgrade cost is 10 × 1.10^level.

## How to run

From this folder:

```bash
flutter pub get
flutter run -d chrome
```
